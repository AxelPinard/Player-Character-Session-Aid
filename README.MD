This software is intended to create DnD 3.5 characters.

Character Package
Character object Contain {Race object, Class object, list Eqipment objects, Ability Score object, HP Object, Characteristics ie age, wight, etc}

Race Package
Race object contain {Name, Size object, speed}

Stats Package
HP Object contain {Current, Maximum}
Size Object contain {Name, AC Mod}
Ability Score Object {Score, Modifier}

Class Package
Class object contain {Name, HD, lvl}

Equipment Package
item Object Contain {name, description, weight, cost}
